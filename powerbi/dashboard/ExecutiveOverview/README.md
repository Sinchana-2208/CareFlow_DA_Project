🏥 CareFlow – Healthcare Process Mining & Executive Overview Dashboard

📊 Power BI | Data Analytics | Healthcare Analytics | Data Visualization

📌 Project Overview

CareFlow is an interactive Healthcare Process Mining and Executive Overview Dashboard developed using Microsoft Power BI.

The project focuses on analyzing healthcare event logs, monitoring patient case activities, understanding case duration, and identifying frequently performed healthcare activities.

The dashboard provides an executive-level overview of healthcare operations through interactive KPIs, activity trends, and case-level analysis, helping stakeholders understand operational patterns and make data-driven decisions.

🎯 Project Objectives

- Analyze healthcare event log data.
- Monitor total patient cases and healthcare events.
- Calculate average case duration.
- Identify the most frequently performed healthcare activities.
- Analyze case-level operational performance.
- Present meaningful insights through an interactive dashboard.

📊 Dashboard Features

1. Executive KPI Overview

The dashboard provides four key performance indicators:

KPI| Value
Total Cases| 1K
Average Case Duration| 28.48
Total Events| 15K
Total Measurements| 8K

2. Healthcare Activity Trend Analysis

- Visualizes healthcare activities.
- Helps understand activity distribution.
- Provides an overview of event patterns.

3. Activity Performance Analysis

- Identifies frequently performed activities.
- Compares event counts across activities.
- Highlights the most common healthcare operations.

4. Case Summary Analysis

- Displays case-level information.
- Analyzes start and end timestamps.
- Examines event counts and case duration.

5. Case Duration Analysis

- Compares average duration across different cases.
- Helps identify variations in case processing time.
- Supports operational performance monitoring.
