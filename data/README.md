Data Directory

This directory contains the datasets used in the CareFlow Process Mining project.

Directory Structure

- "raw/" — Original datasets preserved without modification.
- "processed/" — Cleaned and transformed datasets used for analysis.

Dataset

The project uses the Sepsis Cases Event Log dataset for healthcare process mining and workflow analysis.

Data Handling

Original datasets are stored in the "raw/" directory. Processed datasets and analysis-ready files will be stored in the "processed/" directory.
