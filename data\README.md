Data Directory

This directory is reserved for project data documentation and approved datasets.

Directory Organization

- "raw/" — Original source data, stored locally only when authorized.
- "processed/" — Cleaned and transformed data, stored locally only when authorized.

Data Handling

The original dataset must remain unchanged.

Data-cleaning operations should produce separate processed outputs.

No identifiable patient data, confidential clinical records, or unauthorized data extracts may be committed to GitHub.

If a synthetic or public dataset is used, its source, license, and relevant usage restrictions must be documented.
